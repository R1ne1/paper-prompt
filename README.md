# Paper Prompt

> 一套覆盖学术论文全生命周期的 Prompt 集合，适用于 ChatGPT / Claude / Gemini 等大语言模型。

## Why

写论文的每个环节都有章法可循。好的 Prompt 能让 LLM 从"泛泛而谈"变成"专业搭档"——不是替你写论文，而是帮你把每一步做得更扎实。

## Workflow

按照一篇论文从 0 到 1 的流程，Prompt 被组织为以下阶段：

```
选题构思 → 文献调研 → 大纲搭建 → 论文写作 → 翻译润色 → 审稿投稿
```

---

### 1. 选题与构思

| Prompt | 说明 |
|--------|------|
| [学术idea生成](1-选题与构思/学术idea生成.txt) | 痛点分析 → 多方向头脑风暴 → SWOT 评估，锻造非增量式创新 |

### 2. 文献调研

| Prompt | 说明 |
|--------|------|
| [搜索论文](2-文献调研/搜索论文.txt) | 核心文献推荐、分类文献库、研究空白识别与阅读路径规划 |

### 3. 大纲与结构

| Prompt | 说明 |
|--------|------|
| [论文大纲生成](3-大纲与结构/论文大纲生成.txt) | 基于研究信息生成符合顶会标准的完整英文大纲 |
| [实验设计](3-大纲与结构/实验设计.txt) | Baseline 选取、消融设计、评估指标论证、实验漏洞自查 |

### 4. 论文写作

| Prompt | 说明 |
|--------|------|
| [摘要撰写](4-论文写作/摘要撰写.txt) | 四段式结构，支持精简版/标准版/扩展版字数控制 |
| [Related Work撰写](4-论文写作/Related%20Work撰写.txt) | 三种组织方式（主题/问题/演进），含定位收尾段模板 |
| [段落扩写](4-论文写作/段落扩写.txt) | 将草稿片段扩写为学术规范段落，按章节提供不同策略 |
| [图表描述](4-论文写作/图表描述.txt) | Figure/Table Caption 规范 + 正文结果描述模板 |

### 5. 翻译与润色

| Prompt | 说明 |
|--------|------|
| [中译英](5-翻译与润色/中译英.txt) | 中文学术段落 → 地道英文，消除中式英语 |
| [英译中](5-翻译与润色/英译中.txt) | 英文论文 → 中文，支持精读/学位论文引用/快速概览三种模式 |
| [论文修改](5-翻译与润色/论文修改.txt) | 基于 4C 原则（Clarity/Conciseness/Coherence/Confidence）的深度润色 |
| [降重](5-翻译与润色/降重.txt) | 三级改写力度（保守微调/结构重组/深度重写），针对查重优化 |

### 6. 审稿与投稿

| Prompt | 说明 |
|--------|------|
| [审稿](6-审稿与投稿/审稿.txt) | 模拟顶会审稿人视角，输出完整 Review（Summary/Strengths/Weaknesses/Questions） |
| [Rebuttal](6-审稿与投稿/rebuttal.txt) | 逐条回应审稿意见，含常见质疑应对模板 |

## Quick Start

1. 选择当前阶段对应的 Prompt 文件
2. 将文件内容粘贴到 LLM 对话框作为 System Prompt
3. 按照 Prompt 中的输入要求提供你的论文信息
4. 根据输出进行迭代优化
